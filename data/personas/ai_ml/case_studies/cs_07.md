# Inventory Anomaly Detector for a e-commerce client

**Client:** Blue Labs · **Year:** 2022 · **Industry:** e-commerce

## Problem
The e-commerce team at Blue Labs needed a inventory anomaly detector because their existing process was slow, manual and hard to audit.

## What I built
- Pytorch.
- Automated retraining when data drifted.
- A typed async python rest api with auto-generated docs.
- Search over chunked documents before answering.

## Outcome
The project reduced response time from 15 hours to 4 minutes. The client kept the system in production after handover.
