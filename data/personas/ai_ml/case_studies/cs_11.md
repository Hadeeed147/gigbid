# Recommendation Engine for a SaaS client

**Client:** Pixel Health · **Year:** 2020 · **Industry:** SaaS

## Problem
The SaaS team at Pixel Health needed a recommendation engine because their existing process was slow, manual and hard to audit.

## What I built
- Prompted a large language model to draft replies.
- Scripting the whole pipeline end to end.
- A typed async python rest api with auto-generated docs.
- A calibrated churn classifier with cross-validation.

## Outcome
The project brought report refresh down to 11 minutes. The client kept the system in production after handover.
