# Llm Evaluation Harness for a fintech client

**Client:** Summit Logistics · **Year:** 2021 · **Industry:** fintech

## Problem
The fintech team at Summit Logistics needed a llm evaluation harness because their existing process was slow, manual and hard to audit.

## What I built
- A calibrated churn classifier with cross-validation.
- A background task queue that retried failed jobs overnight.
- Hugging face transformers.
- Trained adapters instead of the full model to save gpu memory.
- Scheduled dags that pulled data every night.

## Outcome
The project saved the team 25 hours a week. The client kept the system in production after handover.
