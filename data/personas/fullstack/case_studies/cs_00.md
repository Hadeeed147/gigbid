# News Site Migration for a manufacturing client

**Client:** Harbor Works · **Year:** 2022 · **Industry:** manufacturing

## Problem
The manufacturing team at Harbor Works needed a news site migration because their existing process was slow, manual and hard to audit.

## What I built
- Postgresql.
- An in-memory cache that cut page loads.
- Reusable ui components with client-side state.
- A batteries-included python web framework with its admin panel.

## Outcome
The project grew active users to 24k. The client kept the system in production after handover.
