# Clinic Appointment System for a education client

**Client:** Cedar Finance · **Year:** 2022 · **Industry:** education

## Problem
The education team at Cedar Finance needed a clinic appointment system because their existing process was slow, manual and hard to audit.

## What I built
- Apollo.
- Hybrid static and server rendering on vercel.
- Redis.
- Stripe.
- React native.

## Outcome
The project reached 70% accuracy on the held-out set. The client kept the system in production after handover.
